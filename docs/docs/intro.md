A modern, **feature-rich** and highly tunable PHP client library for [ScyllaDB](https://github.com/scylladb/scylladb)
and Apache Cassandra 3.0+ using exclusively Cassandra's binary protocol.

> This is a wrapper around the [ScyllaDB C/C++ Driver].

## Getting the Driver

Binary versions of the driver, available for Linux systems and officially supported versions of PHP (8.1, 8.2, 8.3, 8.4),
can be obtained from GitHub Releases **(soon)**.

You're also can compile the driver by yourself or
use [Dockerfile (found in the repository)](https://github.com/he4rt/scylladb-php-driver) with a pre-set environment to
run your tests.
